# Leads de Sites

Painel responsivo (celular e computador) para prospectar lojas locais sem site.

- Importa CSV (Outscraper, Apify, planilha) e remove repetidas
- Filtro "Sem site" por padrão, mais cidade, nicho e busca
- Funil: Novo → Contatado → Respondeu → Proposta → Fechado / Sem interesse
- Botão de WhatsApp com mensagem pronta (editável em "Mensagem")
- Dados ficam no navegador do aparelho (localStorage); use Exportar para backup
- Funciona offline como página única, sem build: abra `index.html`

## Usar no celular
Abra o `index.html` publicado e use "Adicionar à Tela de Início". Os dados ficam
em cada aparelho: para levar do computador ao celular, use Exportar e depois Importar.

`exemplo.csv` mostra as colunas aceitas.
